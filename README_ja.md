# 🎁 GachaPlugin

樽（Barrel）をオリジナルのガチャブロックとして設置・管理できる、シンプルで高機能なMinecraftプラグインです。

## ✨ 主な機能

* **樽をガチャブロック化**: 専用のコマンドを使うだけで、既存の樽を簡単にガチャとして登録できます。
* **柔軟なコスト設定**: 登録時に手に持っているアイテムを「必要アイテム（通貨）」として指定可能。何も持っていない場合は「ノーコスト（無料）」で回せるガチャになります。
* **アイテム消費の切り替え**: ガチャで排出されたアイテムを樽のインベントリから減らす（在庫あり）か、減らさない（無限排出）かを個別に設定できます。
* **直感的なプレビュー機能 (ViewGUI)**: ガチャブロックをスニークしながらクリックすると、排出ラインナップや必要な通貨アイテムをGUIで確認できます。
* **リッチな抽選演出**: ガチャを回すと、ItemDisplayを使用したアイテムが切り替わるアニメーション演出が再生されます。
* **メッセージのカスタマイズ**: すべてのシステムメッセージやエラー文言は `messages.yml` から自由に変更可能です。

---

## 🛠️ 使い方 (How to Use)

### 管理者向け（ガチャの作成）
1. ガチャとして使用したい**樽（Barrel）**を設置します。
2. 樽の中に、**ガチャから排出したいアイテム**を入れます（同じアイテムを複数入れることで排出率の調整も可能です）。
3. 樽に視線を合わせた状態で、コマンド `/gacha set [true/false]` を実行します。
    * 通貨を設定したい場合は、**通貨にしたいアイテムを手に持った状態**でコマンドを実行してください。

### プレイヤー向け（ガチャの回し方・確認方法）
* **ガチャを回す**: 登録された樽を**右クリック**します（通貨が設定されている場合は、そのアイテムを手に持った状態で右クリックします）。
* **中身・必要アイテムの確認**: 登録された樽を**スニーク（Shift）しながらクリック**すると、プレビュー画面（ViewGUI）が開きます。通貨アイテムが設定されている場合は、GUIの中央に表示されます。

## 📦 コマンド一覧 (Commands)

| コマンド | 説明 |
| :--- | :--- |
| `/gacha set [true/false]` | 見ている樽をガチャブロックとして登録します。<br>• **手持ちアイテムあり**: そのアイテムを通貨に設定<br>• **手ぶら**: ノーコスト（無料）に設定<br>• `true`: 当たったアイテムを樽から消費する<br>• `false` *(デフォルト)*: 樽の中身を消費しない |
| `/gacha remove` | 見ているガチャブロックの登録を解除します。 |
| `/gacha open` | 見ているガチャブロックの実際のインベントリ（中身）を開きます。 |
| `/gacha test` | 通貨アイテムを消費せずに、テストとしてガチャを回します。 |
| `/gacha reload_message` | メッセージ設定ファイル（`messages.yml`）を再読み込みします。 |

---

## ⚙️ 設定ファイル (Configuration)

### `messages.yml`
プラグインフォルダ内に自動生成される `messages.yml` を編集することで、ゲーム内で表示されるメッセージやカラーコード（`&`）を自由にカスタマイズできます。編集後は `/gacha reload_message` でサーバーを再起動せずに反映可能です。
